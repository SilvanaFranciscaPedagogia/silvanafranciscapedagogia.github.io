# Psicopedagogia em Poá — Website Profissional

**Landing page institucional de alta conversão** desenvolvida para o consultório de psicopedagogia clínica da profissional **Silvana Francisca Rodrigues Oliveira**, localizado em Poá - SP. 

O site foi projetado sob o conceito *"mobile-first"*, focando em uma experiência de usuário (UX) fluida, carregamento ultra-rápido e técnicas avançadas de SEO local para atração de clientes via Google.

---

## ✨ Funcionalidades e Diferenciais

* **Mínima Latência (Performance Ultra-Rápida):** Todo o CSS foi embutido diretamente na tag `<style>` e a página não depende de frameworks pesados de JavaScript.
* **SEO Avançado e Indexabilidade:** Tags meta completas e configuração de tags Open Graph (`og:image`, `og:title`) e Twitter Cards para compartilhamento impecável em redes sociais.
* **Dados Estruturados (Schema.org):** Inclui marcação JSON-LD do tipo `ProfessionalService`, permitindo que mecanismos de busca (Google) compreendam a área geográfica atendida (Poá - SP), telefone e canais de contato, aumentando as chances de aparecer no Google Mapas.
* **Design Responsivo e Moderno:** Interface adaptável para celulares, tablets e computadores, utilizando tipografia profissional via Google Fonts (`DM Sans` e `Playfair Display`).
* **Foco em Conversão (CTA):** Botão flutuante fixo e chamadas diretas com mensagens pré-configuradas para o WhatsApp.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** (Semântico e acessível)
* **CSS3** (Variáveis nativas, CSS Grid, Flexbox e `@media queries`)
* **JSON-LD** (Dados estruturados para SEO do Google)
